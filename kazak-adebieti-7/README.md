# Қазақ әдебиеті · 7-сынып

«Қазақ әдебиеті» оқулығы (7-сынып; С.Ч. Тұрсынғалиева, Р. Зайкенова, Г.Д. Рысқелдиева;
«Arman-PV» баспасы, Астана, 2025, 272 бет) негізіндегі оқушылар мен мұғалімдерге арналған сайт.

## Бөлімдері

- **Басты бет** — «кітап сөресі»: оқулықтағы 18 шығарма тарау түсімен, оқылғаны белгіленеді; тараулар; күннің сөзі.
- **Шығармалар** — 6 тарау, 22 тақырып оқулықтағы ретімен және беттерімен. Әр шығармада: паспорты (авторы,
  жанры, уақыты, мекені, беттері), шығарма туралы, оқиға желісі, тақырыбы мен идеясы, кейіпкерлері, үзінді,
  бағалы дерек, зерделі сөз, әдебиет теориясы, «Сөзмаржан» сөздері, «Өзіңді тексер» сұрақтары.
- **Ақын-жазушылар** — 14 автор уақыт ретімен: өмірі, өмір белестері, шығармалары, ол туралы айтылған сөз.
- **Кейіпкерлер** — 75 кейіпкер: тарау бойынша сүзу, іздеу, әр кейіпкердің мінезі, рөлі, айтқан сөзі.
- **Уақыт сызығы** — Күлтегін ескерткішінен (732) тәуелсіздік жылдарына дейін: шығармалар, ақын-жазушылар өмірі, тарихи оқиғалар.
- **Сөздік** — әдебиет теориясының 43 термині және «Сөзмаржандағы» 248 сөз.
- **Сайыс** — бес түрлі тест: аралас, шығарма мен автор, кейіпкерлер, әдебиет теориясы, Сөзмаржан.
- **Іздеу** — жоғарғы оң жақтағы белгіше немесе «/» пернесі.

## Мәтінді өзгерту

Барлық мәтін `assets/` ішіндегі деректер файлдарында:

| Файл | Мазмұны |
|---|---|
| `data-1.js` | Кітап, тараулар, I–II тараулардың тақырыптары |
| `data-2.js` | III–VI тараулардың тақырыптары, өңірлер |
| `data-3.js` | Ақын-жазушылар және кейіпкерлер |
| `data-4.js` | Әдебиет теориясы терминдері және «Сөзмаржан» |
| `data-5.js` | Уақыт сызығы және сайыс сұрақтары |

Тек тырнақшадағы мәтінді өзгертіңіз, тырнақша мен үтірлерді өшірмеңіз.

## GitHub Pages-ке жариялау

1. **Settings → Pages → Branch: `main` / `(root)` → Save**.
2. Бір-екі минуттан кейін сайт `https://<аккаунт>.github.io/<репозиторий>/` мекенжайында ашылады.

Сайтқа сурет жүктелмейді: шығармалардың белгілері мен ою-өрнек сызбамен салынған, сондықтан сайт жеңіл ашылады.
